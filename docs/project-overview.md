# Project Overview

## Purpose

The Open Source Contribution Tracker is a software application designed to help developers organize and monitor their contributions to open-source projects.

## Problem

Developers may contribute to multiple repositories, issues, and pull requests. Keeping track of these contributions manually can become difficult.

The application aims to provide a centralized place to manage this information.

## Target Users

The primary users are:

* Students learning open-source development
* Beginner developers
* Open-source contributors
* Developers managing multiple contributions

## Core Concepts

The system will eventually manage:

* Users
* Open-source projects
* Issues
* Pull requests
* Contributions
* Contribution statuses

## Future Development

The application will be developed incrementally through multiple phases covering:

1. Project and open-source foundation
2. Backend and database
3. Frontend and API integration
4. Testing, security, and CI/CD
5. Open-source collaboration and contribution
