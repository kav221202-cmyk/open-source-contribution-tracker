# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, respectful, and inclusive environment for everyone participating in this project.

## Expected Behavior

Contributors are expected to:

* Be respectful and professional.
* Communicate constructively.
* Accept reasonable feedback.
* Focus on improving the project.
* Respect different perspectives and levels of experience.

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment
* Personal attacks
* Discrimination
* Threats
* Deliberate disruption
* Sharing private information without permission

## Reporting

If you experience or witness unacceptable behavior, please report it to the project maintainer through the appropriate project communication channel.

## Enforcement

Project maintainers may take appropriate action when this Code of Conduct is violated.
