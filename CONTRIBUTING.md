# Contributing to Open Source Contribution Tracker

Thank you for your interest in contributing to this project.

## Getting Started

1. Fork the repository.
2. Clone your fork.
3. Create a new branch for your contribution.
4. Make your changes.
5. Run the available tests.
6. Commit your changes.
7. Push your branch to GitHub.
8. Open a pull request.

## Branch Naming

Use descriptive branch names.

Examples:

* `feature/user-registration`
* `feature/contribution-dashboard`
* `fix/login-validation`
* `docs/update-readme`

## Commit Messages

Write clear and descriptive commit messages.

Examples:

* `Add user registration`
* `Fix contribution status validation`
* `Update API documentation`

## Pull Requests

Pull requests should:

* Clearly explain what was changed.
* Explain why the change was necessary.
* Include relevant tests where appropriate.
* Avoid unrelated changes.

## Code Quality

Please keep code:

* Readable
* Maintainable
* Consistent
* Properly tested

## Questions

If you are unsure about a contribution, open an issue and describe the problem or proposed change.
