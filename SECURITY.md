# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please do not publicly disclose the vulnerability before it has been investigated.

Report security issues privately to the project maintainer.

Please include:

* A description of the vulnerability
* Steps to reproduce the issue
* The potential impact
* Any suggested mitigation

## Supported Versions

During development, the latest version of the project will be the primary supported version.

## Security Updates

Security issues will be investigated and addressed as appropriate.
